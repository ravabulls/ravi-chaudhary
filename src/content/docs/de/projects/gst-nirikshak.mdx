| Schlüssel | Was er verbindet | Welche Frage er beantwortbar macht |
|---|---|---|
| **GSTIN** | Die Registrierungsnummer in Erklärungen, E-Way-Bills und Meldungen Dritter | Stimmt, was das Unternehmen angibt, mit dem überein, was andere über es melden? |
| **PAN** | Alle Registrierungen eines Unternehmens und seine Einkommensteuerdaten | Ist ein Unternehmen auf mehrere Registrierungen verteilt? |
| **Zeitraum** | Monate und Geschäftsjahre über Erklärungen und Bücher | In welchen Monaten entsteht eine Lücke, und sind Zinsen fällig? |
| **Rechnung + Lieferant** | Das Einkaufsjournal gegen die Meldungen der Lieferanten | Welche Vorsteuer hat keine passende Rechnung oder wird doppelt geltend gemacht? |
| **Fahrzeug + Zeit** | E-Way-Bills gegen Bewegungsdaten | Konnte die Ware auf diesem Beleg tatsächlich transportiert worden sein? |
| **PIN-Code** | Adressen zu ungefähren Standorten | Ist die angegebene Entfernung für diese Strecke plausibel? |
| **Warencode + Datum** | Waren zum Rechtsstamm und zu Gleichartigen | Wurde an diesem Tag der richtige Satz angewendet? Weicht eine Firma stark von Gleichartigen ab? |
| **Name, Adresse, Telefon** | Unscharfer Abgleich über Registrierungen und frühere Fälle | Sind angeblich unabhängige Firmen in Wahrheit verbunden? Wurde dieser Hinweis schon geprüft? |

## Ein Durchlauf mit synthetischen Daten

Die App enthält eine Demonstration. Sie zeigt, wie jede weitere Quelle eine zusätzliche Beweisebene hinzufügt. Alle Firmen und Zahlen sind synthetisch.

<Steps>

1. **Erkennen.** Screenings über die Grundgesamtheit setzen eine Gruppe eng verbundener Neuregistrierungen an die Spitze der Arbeitsliste, jeweils mit Punktwert und Begründung.

2. **Verbinden.** Lieferbeziehungen aus Erklärungen, Einkaufsaufstellungen und E-Way-Bills ergeben ein Netzwerk aus 18 Einheiten. Die Graphsuche findet einen Ring aus vier Firmen, die Vorsteuer im Kreis weitergeben, und zwei Firmen mit Vorsteuer, aber ohne echte Einkäufe, die alle einen Begünstigten speisen (das Bild oben auf dieser Seite). Die Analyse dauert etwa eine Zehntelsekunde.

3. **Prüfen.** Die 95 E-Way-Bills des Rings werden darauf geprüft, ob die Ware physisch bewegt worden sein kann: 36 Sendungen fallen durch, die Steuer darauf wird exakt berechnet, für die nicht geprüften Belege gibt es eine klar gekennzeichnete Schätzung.

4. **Erhärten.** Finanzdaten zeigen Geld, das zwischen zwei der Firmen im Kreis fließt, passend zum Muster im Netzwerk.

5. **Erklären.** Jede Feststellung wird zu einem Befund mit Rechtsgrundlage, Methode (exakt oder geschätzt), Konfidenz und Quellzeilen. Der Beamte entwirft den Bericht mit Anlagen; eine vorgesetzte Person genehmigt ihn, bevor er registriert wird.

6. **Handeln.** Für einen verwandten Fall berechnet die App die Steuer je Monat, Zinsen taggenau, bereits geleistete Zahlungen, Optionen für Strafzuschläge und die gesetzlichen Fristen.

</Steps>

## Technik und Architektur

Eine lokale Webanwendung: ein Python-Server auf dem eigenen Rechner des Beamten und der normale Browser als Oberfläche. Kein Internet, keine Cloud, keine Installationsrechte nötig.

| Schicht | Werkzeuge | Warum |
|---|---|---|
| **Analyse-Engine** | DuckDB (eingebettetes SQL), PyArrow | Schnelle spaltenorientierte Analyse großer Auszüge auf einem Rechner, ohne Datenbankserver |
| **Graph und Abgleich** | Eigene Graphalgorithmen, RapidFuzz | Kreisgeschäfte, Cluster und Kettenstufen; unscharfer Abgleich von Namen und Adressen |
| **Dateiverarbeitung** | python-calamine, pypdfium2, JSON- und CSV-Leser | Erklärungen und Berichte aus Excel, PDF, JSON und CSV lesen |
| **Dokumente** | python-docx, XlsxWriter, Pillow | Berichte, Schreiben, Anlagen und Netzwerkbilder im Format der Behörde |
| **Webserver** | FastAPI, Uvicorn, Jinja2 | Ein testbarer Server mit serverseitig erzeugten Seiten |
| **Oberfläche** | HTMX, Alpine.js, Tabulator, Cytoscape.js | Interaktive Tabellen und Netzwerkbilder, alles lokal gebündelt |
| **Sicherheit** | cryptography (Ed25519), Argon2, SHA-256 | Signaturen, versiegelte Pakete, Passwörter und Datei-Fingerabdrücke |
| **Qualität** | pytest, Hypothesis, pytest-socket | Unit-Tests, eigenschaftsbasierte und offline erzwungene Tests |
| **Paketierung** | PyInstaller, portable Version | Läuft auf abgesicherten Windows-Rechnern ohne Administratorrechte |
| **KI-Unterstützung** | ChatGPT (GPT-4), GitHub Copilot | Entwürfe und Durchsicht von Code, Tests und Dokumentation, stets geprüft gegen Spezifikation und Tests |
