Der Denkwandel, durch den dieser ganze Block klickt: Angreifer haben es nicht auf *mich* persönlich abgesehen — sie zielen auf *alle*, automatisiert und in großem Maßstab. „Bei mir gibt es nichts zu holen" ist falsch. Allein meine E-Mail ist der Generalschlüssel: Die Passwort-Zurücksetzung jedes anderen Kontos landet dort. Nichts davon ist also Paranoia; es ist eine Handvoll langweiliger Gewohnheiten, die mich zu einem schwereren Ziel machen als die meisten.

## 1 · Sicherheit

### Passwörter — Länge schlägt Komplexität

Widersprüchlich, aber wahr: Ein langes Passwort lässt sich schwerer knacken als ein kurzes, kompliziertes. `P@s5w0rt!` sieht hart aus, ist aber kurz und damit schwach. Die Stärke wächst mit jedem zusätzlichen Zeichen.

- **Passphrase** = der günstige Weg zu Länge: vier zufällige, unzusammenhängende Wörter aneinandergereiht. Lang (stark) *und* einprägsam (damit ich sie nie auf einen Klebezettel schreibe).
- **Wiederverwendung ist die eigentliche Gefahr** — größer als jedes einzelne schwache Passwort. Seiten werden gehackt, gespeicherte Passwörter gelangen an die Öffentlichkeit, dann probieren Angreifer sie automatisch bei meiner E-Mail, meiner Bank, überall aus. Das ist **Credential Stuffing**: Ein wiederverwendetes Passwort öffnet mein ganzes Leben. (Bei Have I Been Pwned kann ich prüfen, ob meine E-Mail in bekannten Leaks auftaucht.)
- **Passwortmanager** — ein Programm, das pro Konto ein einzigartiges, starkes Passwort erzeugt und sich merkt, alles hinter einer einzigen Master-Passphrase verschlossen. Ich merke mir eine Sache; er merkt sich den Rest.

<Aside type="tip" title="2FA — ein zweites Schloss an der Tür">
**Zwei-Faktor-Authentifizierung (2FA)** verlangt einen zweiten Nachweis über das Passwort hinaus — meist einen Code oder eine Bestätigung auf meinem Handy. Selbst ein gestohlenes Passwort kann sich ohne den zweiten Faktor nicht anmelden. Es ist die Geldautomaten-Logik: Karte (**etwas, das ich habe**) + PIN (**etwas, das ich weiß**), jedes allein nutzlos. Wenn die Bank mich bittet, eine Überweisung ein zweites Mal zu bestätigen, *ist* das genau dieser zweite Faktor bei der Arbeit.
</Aside>

### Die Bedrohungen, ohne das Kino-Drama

**Schadsoftware** (Malware) ist der Oberbegriff für schädliche Software. Sie ist bloß Software, die tut, was ihr Autor ihr aufgetragen hat — und sie braucht immer einen *Weg hinein*.

| Bedrohung | Was sie tut |
|---|---|
| Virus | Schadsoftware, die sich verbreitet, indem sie sich an andere Dateien heftet |
| Ransomware | Sperrt meine Dateien, verlangt Zahlung zum Entsperren |
| Malware (allgemein) | Programme, die schädigen, ausspähen oder erpressen sollen |

Die meisten Infektionen beginnen mit einer **ganz gewöhnlichen menschlichen Handlung**, nicht mit genialem Hacking: einen unerwarteten Anhang öffnen, auf einen überzeugenden Link klicken, von einer inoffiziellen Seite herunterladen, einen gefundenen USB-Stick einstecken. Das wahre Können des Angreifers ist *Überzeugungskraft*. Deshalb sind die beiden Verteidigungen, die die meiste Arbeit leisten, ziemlich langweilig:

<Steps>
1. **Updates zügig installieren.** Sie stopfen genau die Löcher, die Angreifer nutzen — „später erinnern" ist eine Sicherheitsentscheidung. (WannaCry 2017 verbreitete sich nur auf Rechnern, die ein verfügbares Update übersprungen hatten; aktuelle Computer waren sicher.)
2. **Bewusst entscheiden, was ich öffne, anklicke, installiere.** Nur offizielle Quellen. Ein Virenscanner ist ein Werkzeug, kein Schutzschild — er kann mich nicht davon abhalten, mein Passwort auf einer gefälschten Seite einzutippen.
</Steps>

### Phishing — die eine Fähigkeit, die ich wirklich lernen sollte

**Phishing** = gefälschte Nachrichten, verkleidet als etwas, dem ich vertraue, um mir Passwörter, Geld oder Informationen zu entlocken. Es ist der häufigste Angriff, dem ich begegnen werde, und die Verteidigung ist voll erlernbar. In Deutschland die üblichen Kostüme: eine „DHL/Deutsche Post"-SMS zu einem Paket, die eine kleine Zollgebühr will, eine „Sparkasse"- oder „PayPal"-Warnung, dass mein Konto gesperrt wird, wenn ich mich nicht *jetzt* anmelde, eine dringende Bitte von einem „Chef".

**Phishing-Warnzeichen-Checkliste** — auf alles anwenden, das sich verdächtig anfühlt:

| # | Prüfung | Warnzeichen |
|---|---|---|
| 1 | Wer hat wirklich gesendet? | Die *tatsächliche* Adresse lesen, nicht den angezeigten Namen |
| 2 | Dringlichkeit? | Drohungen und Fristen sind die Handschrift des Betrügers |
| 3 | Wohin führt der Link? | Mit der Maus darüberfahren zur Vorschau; ist die Domain echt? |
| 4 | Verlangt es etwas, das es nicht sollte? | Echte Organisationen fragen nicht per E-Mail nach Passwörtern |
| 5 | Im Zweifel → direkt gehen | Die Adresse selbst eintippen / die offizielle App nutzen — **niemals über den Link der Nachricht prüfen** |

<Aside type="caution" title="Zwei Phishing-Mythen">
- *„Schlechte Rechtschreibung verrät es."* Viele Fälschungen sind hochwertig und vom Original nicht zu unterscheiden. Beurteile das **Muster**, nicht die Rechtschreibung.
- *„Wenn es meinen Namen kennt, ist es echt."* Details gelangen an die Öffentlichkeit und werden gekauft. Personalisierung macht eine Fälschung überzeugender, nicht echter — die Checkliste trotzdem durchgehen.
</Aside>

### Sicheres Surfen & HTTPS

<Aside type="note" title="Das Schloss bedeutet privat, nicht ehrlich">
`https` + das Schloss bedeuten, dass die **Verbindung verschlüsselt** ist, sodass niemand mithören kann. Es bedeutet **nicht**, dass die Seite meine Daten verdient — Betrugsseiten haben auch Schlösser. Sein *Fehlen* auf einer Login- oder Zahlungsseite ist ein Warnzeichen; seine *Anwesenheit* ist kein Gütesiegel. Ich lese trotzdem die Domain.
</Aside>

**Verschlüsselung** = Daten verwürfeln, sodass nur der Schlüsselinhaber sie lesen kann. Zwei Varianten sind der Nennung wert:

| | Wo | Geschützt durch |
|---|---|---|
| **Bei der Übertragung** | Daten, die zwischen Gerät und Seite unterwegs sind | HTTPS, VPN („sicherer Tunnel") |
| **Im Ruhezustand** | Daten, die auf einem Gerät/Server gespeichert liegen | Geräte-/Festplattenverschlüsselung — gestohlene Hardware bleibt unlesbar |

Zwielichtige Seiten nutzen visuelle Tricks: Pop-ups, die „Sie sind infiziert!" schreien (die „Lösung" *ist* die Infektion), gefälschte grüne Download-Buttons, größer als der echte Link, „Sie haben gewonnen"-Banner. Die Gewohnheit, die sie alle schlägt: **langsamer werden und vor dem Klicken lesen; alles schließen, das schreit.** Banking/Shops/Portale durch Eintippen der Adresse oder über die offizielle App erreichen — niemals über den Link einer Nachricht.

## 2 · Privatsphäre & Daten

### Die Spur, die ich hinterlasse

Allein das Nutzen des Internets hinterlässt Krümel: besuchte Seiten, Suchanfragen, Likes, Standort, welche Apps und wann. Einzeln harmlos; zusammengesetzt ergeben sie ein detailliertes, kommerziell wertvolles Bild von mir — weshalb so viel des Webs darauf ausgelegt ist, sie zu sammeln.

- **Cookies** = kleine Daten, die eine Seite in meinem Browser speichert. *Notwendige* halten mich angemeldet / bewahren einen Warenkorb; *Tracking*-Cookies verfolgen mich über Seiten hinweg. Das Einwilligungsbanner (deutsch: **Datenschutz**) ist die Seite, die um Erlaubnis bittet — „ablehnen" / „nur notwendige" ist eine legitime, nahezu kostenlose Wahl.
- **Digitaler Fußabdruck** = alles, was ich öffentlich poste (und vieles, was andere über mich posten). Er ist **durchsuchbar** (Arbeitgeber, Vermieter schauen nach) und **beständig** (Löschen tilgt keine Screenshots und Archive). Test vor dem Posten: *Wäre es mir recht, wenn ein künftiger Arbeitgeber das aus dem Zusammenhang gerissen läse?*

<Aside type="caution" title="Datenschutz-Mythen">
- *„Inkognito macht mich anonym."* Es verhindert nur, dass mein *eigener* Browser lokal Verlauf speichert. Mein Anbieter, das Netzwerk und die Seite sehen weiterhin alles. Privatsphäre vor Mitbewohnern, nicht vor dem Internet.
- *„Gelöscht = weg."* Kopien bleiben bestehen. Öffentliches Posten als dauerhaft behandeln.
</Aside>

### Backups — das Netz unter allem

Jede andere Verteidigung kann versagen. Ein **Backup** (eine Kopie wichtiger Dateien, anderswo aufbewahrt) macht ein Versagen überlebbar und deckt *jedes* Unglück auf einmal ab — Diebstahl, verschütteter Kaffee, defekte Festplatte, Ransomware. Mit einem Backup verliert die Dateisperre des Angreifers jede Macht.

<Aside type="tip" title="Sicherheit betrifft auch andere">
Bei der Arbeit hören meine Gewohnheiten auf, privat zu sein. Die meisten Firmen-Sicherheitsvorfälle beginnen mit dem einen Klick **eines einzigen** Mitarbeiters; von diesem Brückenkopf aus bewegen sich Angreifer nach innen. Meine Passphrase, 2FA und die Checklisten-Pause werden Teil der Verteidigung des Teams — niemand will die unverschlossene Tür sein. Sorgsam mit den Daten anderer umzugehen ist eine berufliche Pflicht (und wird in der Unternehmens-/SAP-Welt sehr ernst genommen).
</Aside>

## 3 · Informationskompetenz

Das Internet hat *jeden* zum Publizisten gemacht — kein Redakteur, kein Faktenchecker, kein Name nötig. Falschheit reist nun exakt wie die Wahrheit gekleidet, also ist das Prüfen, das einst die Torwächter erledigten, jetzt meine Aufgabe.

<Aside type="note" title="Daten → Information → Wissen">
**Daten** = rohe Fakten (eine Liste von Zahlen). **Information** = Daten, zu Bedeutung geordnet („die Temperaturen lagen über dem Durchschnitt"). **Wissen** = Information, die ich verstanden, verknüpft habe und nutzen kann. Das Netz überschwemmt mich mit den ersten beiden; Wissen muss ich noch *aufbauen* — aus Quellen, denen ich vertrauen kann.
</Aside>

### Eine Quelle beurteilen — wer / wann / warum

| Frage | Was ich prüfe |
|---|---|
| **Wer** hat es veröffentlicht? | Ein echter Name/eine Organisation mit einem Ruf zu verlieren, oder anonym? |
| **Wann**? | Noch aktuell, oder eine alte Geschichte, neu aufgewärmt? |
| **Warum**? | Motiv: informieren, verkaufen, überzeugen oder mich *aufregen* (Wut = Klicks)? |

Schlagzeilen sind geschrieben, um angeklickt, nicht um akkurat zu sein — und das meiste Teilen erledigen Leute, die nur die Schlagzeile gelesen haben. Der peinlich einfache Vorteil: **öffnen und lesen, bevor ich glaube oder teile.** (Dieselbe Studie, zwei Schlagzeilen: „KAFFEE MIT LÄNGEREM LEBEN VERKNÜPFT" vs. „WISSENSCHAFTLER WARNEN VOR KAFFEEGEWOHNHEITEN" — in der Lücke zwischen Schlagzeile und Inhalt wohnt die Verzerrung.)

### Falsch vs. irreführend

| | Absicht | Meine Reaktion |
|---|---|---|
| **Fehlinformation** | Ehrlicher Irrtum — ein Freund teilt einen falschen Tipp, den er glaubt | Eine sanfte Richtigstellung |
| **Desinformation** | Bewusste Täuschung — eine koordinierte Kampagne | Nichts, nicht einmal der wütende Zitat-Post, der sie verstärkt |

Inhalte verbreiten sich, weil sie *dafür konstruiert* sind: **Clickbait** verspricht mehr, als er liefert; Empörung verbreitet sich am schnellsten. Die Regel, die daraus folgt: **eine starke emotionale Reaktion ist ein Signal, langsamer zu werden, nicht zu teilen.** Und „ich habe ein Foto/Video gesehen" ist kein Beweis mehr — KI kann überzeugende Bilder, geklonte Stimmen und Deepfake-Videos fabrizieren. Auffälliger Inhalt wird *verifiziert*, bevor er geglaubt wird.

### Gegenprüfen & ehrliche Nutzung

<Steps>
1. **Laterales Lesen** — eine verdächtige Seite nicht härter studieren; sie *verlassen*. Einen neuen Tab öffnen und *über die Quelle* suchen: wer betreibt sie, was sagen andere, wurde sie gemeldet? Eine hochwertige Seite kann nicht steuern, was der Rest des Webs über sie sagt. Die wirksamste Verifikationsgewohnheit überhaupt.
2. **Zum Ursprung zurückverfolgen** — auffällige Behauptungen kommen aus zweiter oder dritter Hand; die Kette zurückverfolgen bis zur eigentlichen Studie/dem Dokument und prüfen, ob es das wirklich sagt.
3. **Unabhängige Bestätigung finden** — zehn Posts, die alle einen Ursprung zitieren, sind *eine* Quelle in zehn Kostümen. Unabhängigkeit vervielfacht Glaubwürdigkeit; Wiederholung nicht.
</Steps>

<Aside type="tip" title="Informationen ehrlich nutzen">
**Anerkennung geben** — nennen, woher eine Idee stammt; fremde Arbeit als eigene auszugeben ist Plagiat, und das zählt in diesem Programm und an jedem Arbeitsplatz. **Ehrlich umformulieren** — Umformulieren beweist, dass ich es verstanden habe, hebt aber *nicht* die Pflicht zur Quellenangabe auf; kurze wörtliche Zitate kommen in Anführungszeichen mit genannter Quelle. (Das oberste Suchergebnis ≠ das zuverlässigste — das Ranking ist Relevanz und Popularität, nicht Wahrheit.)
</Aside>

## 4 · Digitale Verantwortung & Rechte

**Online ist keine getrennte moralische Welt.** Der Bildschirm schafft Distanz, und Distanz verleitet Menschen dazu, Standards fallenzulassen, die sie von Angesicht zu Angesicht wahren würden — doch die Person auf der anderen Seite ist genauso real. Ich brauche keine neue Ethik fürs Internet; ich brauche den Mut, meine bestehende beizubehalten. Und mein Verhalten fügt sich ebenfalls dem durchsuchbaren, beständigen Fußabdruck hinzu.

**Andere respektieren** läuft auf drei Gewohnheiten hinaus:

| Gewohnheit | Die Grenze |
|---|---|
| Widersprechen, nicht angreifen | Sich mit dem *Gesagten* auseinandersetzen (in Ordnung); die *Person* angreifen — besonders wiederholt — ist Belästigung. **Trolling** = Provokation zum Spaß, auf der falschen Seite. Test: gehe ich auf die Behauptung ein, oder versuche ich, den zu verletzen, der sie geäußert hat? |
| Einwilligung vor dem Teilen | Posts *über andere* geben *deren* Privatsphäre aus — vor dem Teilen von Fotos, Geschichten oder Screenshots, die sie betreffen, fragen (doppelt bei Sensiblem) |
| Gut widersprechen | Auf ihr stärkstes Argument antworten, die Behauptung kritisieren, nicht die Person, in einem Ton auf Augenhöhe schreiben und wissen, wann man geht (das ist Urteilsvermögen, kein Verlieren) |

### Datenschutz, DSGVO & meine EU-Rechte

<Aside type="note" title="Der ganze Gedanke in einem Satz">
**Meine personenbezogenen Daten gehören mir.** Informationen über mich sind kein freier Rohstoff — Organisationen brauchen einen *rechtmäßigen Grund* (oft meine Einwilligung), um sie zu nutzen, mit Pflichten verbunden. Alles andere folgt aus diesem Satz.
</Aside>

Das Gesetz, das dies EU-weit trägt, ist die **DSGVO** (Datenschutz-Grundverordnung). Auf meiner Ebene bedeutet es, dass Organisationen müssen:

- **Mir sagen**, was sie erheben und warum (Datenschutzerklärungen, Datenschutzhinweise)
- **Nur erheben**, was sie brauchen, und es angemessen **schützen**
- **Meine Rechte respektieren**: zu *erfahren*, was sie gespeichert haben, Fehler zu *korrigieren* und in vielen Fällen Daten *löschen* zu lassen

Sie hat Zähne — hohe Bußgelder für den falschen Umgang mit Daten sind der Grund, warum europäische Organisationen das ernst nehmen und nicht als Zierde. Cookie-Banner, Einwilligungsanfragen und Datenschutzerklärungen sind nur diese sichtbar gemachten Rechte; nicht notwendiges Tracking abzulehnen ist eine Wahl, die das Gesetz mir bewusst gibt.

<Aside type="caution" title="Eigentum & Ethik der Technik">
- **Urheberrecht** ist automatisch — „es steht im Internet" ≠ „frei nutzbar". Weiterverwendung braucht Erlaubnis oder eine erlaubende Lizenz, immer mit Quellenangabe. Das deutsche/EU-Recht kennt **kein breites „Fair Use" nach US-Vorbild** — nur engere Ausnahmen wie kurze, belegte Zitate zu Studien-/Kommentarzwecken. Im Zweifel: lieber nicht.
- **Verzerrung rein, Verzerrung raus** — Software wirkt neutral, lernt aber aus Daten, und Daten tragen die Ungerechtigkeit der Welt in sich (dokumentiert bei Einstellungs- und Gesichtserkennungswerkzeugen). **„Der Computer hat entschieden" ≠ „gerecht."** Die Erbauer — bald auch ich — tragen die Pflicht zu prüfen, und „der Algorithmus war's" ist nie eine Antwort für Verantwortung.
</Aside>

## 5 · Wohlbefinden

Viele Stunden am Bildschirm jetzt und eine ganze Laufbahn danach. Mein Körper und meine Aufmerksamkeit sind die Ausrüstung, die ich am längsten nutzen werde.

**Ergonomie** = den Arbeitsplatz an meinen Körper anpassen, nicht umgekehrt:

- Rücken gestützt, beide Füße auf dem Boden.
- Oberkante des Bildschirms ≈ Augenhöhe (Nacken neutral, nicht stundenlang gebeugt).
- Tastatur/Maus nah, damit die Schultern entspannt bleiben.
- Günstigstes Upgrade, wenn ein Laptop mein Hauptgerät ist: ihn erhöhen (Bücher tun es) + eine separate Tastatur ergänzen.
- **Augen**: oft für einen kurzen Moment in die Ferne schauen (der ~20-Minuten- / ~20-Sekunden-Rhythmus) — reduziertes Blinzeln + fixierter Fokus ist es, was sie ermüdet. Den Raum beleuchtet halten.
- **Bewegung**: kurze regelmäßige Pausen setzen Körper *und* Aufmerksamkeit zurück. Die Pause ist Teil der Arbeit.

<Aside type="tip" title="Meine Aufmerksamkeit verteidigen — Struktur schlägt Willenskraft">
Endloses Scrollen und Autoplay sind von Teams **so konstruiert**, dass man sie schwer weglegen kann (selbst ihre Designer begrenzen die eigene Nutzung). Ich schiebe es nicht auf meine Willenskraft — ich nutze **Struktur**: Benachrichtigungen aus beim Lernen, Handy in einem anderen Raum, geplante Blöcke. Jede Unterbrechung kostet weit mehr als ihre Sekunden, weil der Geist lange braucht, um vollständig zurückzukehren, also ist eine mit Pings gespickte Stunde viel weniger wert als eine ununterbrochene. **Deep Work** (fokussiert, ununterbrochen — wo Lernen geschieht) und **Shallow Work** (Nachrichten, kleine Aufgaben) vertragen sich nicht.
</Aside>

**Gesunde Beziehung** = Ausrichtung, nicht Verzicht. Bemerken, wohin die Zeit tatsächlich geht (ohne Schuldgefühle), dann fragen: *passt das zu dem, was ich will?* Grenzen halten, wenn sie strukturell sind (Handy anderswo, Benachrichtigungen standardmäßig aus, ein bildschirmfreier Punkt vor dem Schlaf) statt heroisch. Die Vergleichsfalle mit den anderen ist manipuliert — ich sehe die Höhepunkte aller und mein eigenes Innenleben; der ehrliche Maßstab ist ich vs. letzter Monat. Wenn Technik Schlaf, Stimmung oder Beziehungen kostet: Struktur straffen, jemandem davon erzählen und eine Fachperson fragen, wenn es sich größer anfühlt.

## 6 · KI-Kompetenz

<Aside type="note" title="LLM auf einen Blick — sagt voraus, weiß nicht">
**Maschinelles Lernen** = Muster, die aus vielen *Beispielen* aufgesogen werden, nicht von Hand geschriebene Regeln (bringe „Katze" bei, indem du eine Million beschriftete Fotos zeigst, kein Regelbuch). Ein **LLM (großes Sprachmodell)** erzeugt die *plausibelste Fortsetzung*, ein Stück nach dem anderen. Der eine Satz fürs Leben: **diese Systeme sagen voraus, sie wissen nicht** — Flüssigkeit ist Muster, kein Verständnis, also klingen sie genauso selbstsicher, wenn sie falsch liegen.
</Aside>

**Stark bei** Musterarbeit: entwerfen, umformulieren, zusammenfassen, übersetzen, Code vorschlagen, Bildinhalte erkennen. **Schwach bei** genau dort, wo Vorhersage nicht genügt: garantierte Fakten, präzise Arithmetik, Ereignisse nach dem Trainingsstichtag und dem Urteil darüber, was zählt.

### KI-Werkzeuge gut nutzen

<Steps>
1. **Mit Zweck, Kontext und Vorgaben prompten.** Vage rein, generisch raus. Nicht „schreib über E-Mail", sondern „erkläre Antworten vs. Allen antworten für einen neuen Büromitarbeiter, fünf schlichte Sätze, ein Beispiel."
2. **Es als Gespräch behandeln, nicht als Automaten.** Erste Antwort = ein Entwurf. Verfeinern: „kürzer", „förmlicher", „du hast X angenommen, tatsächlich Y". Iteration *ist* die Methode — gute Ergebnisse kommen aus besseren Gesprächen, nicht aus magischen ersten Prompts.
3. **Alles Faktische prüfen.** Weil es voraussagt, **halluziniert** es: flüssiger, spezifischer, plausibler, *falscher* Inhalt — erfundene Quellen und Statistiken, die perfekt aussehen. (Echte Anwälte wurden sanktioniert, weil sie KI-erfundene Fallzitate einreichten.) Ich bin der Redakteur; mit meinen Gewohnheiten des lateralen Lesens verifizieren, bevor ich mich darauf verlasse.
</Steps>

<Aside type="caution" title="KI-Grenzen & der Arbeitsplatz">
- **Verzerrung rein, Verzerrung raus** — Ausgaben über Menschen/Gruppen bekommen denselben kritischen Blick wie jede Quelle.
- **Datenschutz-Grenzlinie** — das Chatfenster *fühlt* sich privat an, aber was ich eintippe, wird an das Unternehmen gesendet (und vielleicht dort gespeichert). **Personenbezogene Daten, Passwörter und vertrauliches/firmeneigenes Material kommen niemals hinein.** Dieses „fasse einfach dieses Dokument zusammen"-Einfügen kann Kundendaten an eine externe Partei übertragen.
- **KI-Regeln des Arbeitgebers** existieren, weil echte Leaks passiert sind — freigegebene Werkzeuge, welche Daten erlaubt sind, was geprüft werden muss. Es ist die Datenschutz-Grenze, verbindlich gemacht; innerhalb davon arbeiten.
- **Übermäßiges Verlassen** — KI nutzen, um zu *beschleunigen, was ich verstehe*, niemals um Verständnis zu ersetzen, das ich nie aufgebaut habe. Beim Lernen *ist* das Ringen das Lernen. Alles verantworten, was sie in meinem Namen tut.
</Aside>

**KI bei der Arbeit**: Sie automatisiert *Aufgaben* (routinemäßige Musterarbeit) schneller als ganze Berufe; die Arbeit verschiebt sich hin zu Urteilsvermögen, Verantwortung, unordentlichem menschlichem Kontext und der Beaufsichtigung der Maschinen — und neue Rollen wachsen *rund um* die Technik, genau in der Unternehmens-/SAP-Welt. „Mit KI arbeiten" ist selbst eine Fähigkeit, deren Teile ich nun besitze: klar prompten, verifizieren, wissen, was nie geteilt wird, das Ergebnis verantworten. Das Werkzeug wie eine fähige Nachwuchskraft behandeln: schnell, unermüdlich, braucht bei allem Wichtigen Aufsicht. Für welchen Hype als Nächstes auch kommt — fragen: *was tut es tatsächlich, worin ist es gut/schlecht, wer profitiert vom Hype* — die Bewertungsfähigkeit überdauert jede einzelne Technologie.

## 7 · Barrierefreiheit

<Aside type="note" title="Barrierefreiheit — frei von Barrieren">
**Barrierefreiheit** = so gestalten, dass alle teilhaben können, auch Menschen mit Behinderungen. Das Hindernis ist meist die **Gestaltung, nicht die Person**: eine Treppe blockiert einen Rollstuhl (eine Rampe beseitigt es); ein Video ohne Untertitel blockiert einen gehörlosen Nutzer (Untertitel beseitigen es); ein unbeschriebenes Bild blockiert einen blinden Nutzer (eine Zeile Alt-Text beseitigt es). Die meisten Beseitigungen sind überraschend klein.
</Aside>

**Fähigkeit variiert über jedes Leben hinweg** — keine feste Nischengruppe:

| Fall | Sehen | Hören | Motorik |
|---|---|---|---|
| **Dauerhaft** | Blind | Gehörlos | Fehlender/eingeschränkter Arm |
| **Vorübergehend** | Augeninfektion | Ohrenentzündung | Arm im Gips |
| **Situativ** | Grelle Sonne auf dem Bildschirm | Lauter Zug | Ein Baby tragen, ein Arm frei |

Gestaltung, die den dauerhaften Fall bewältigt, bewältigt alle anderen gratis. Das ist der **Bordstein-Effekt** (curb-cut effect): die Bordsteinrampe, für Rollstühle gebaut, sofort geliebt von Kinderwagen, Koffern, Radfahrern, Lieferungen. Für einige gebaut, für alle besser — Untertitel sind die Software-Version (Pendler, stummgeschaltete Bildschirme, Zuschauer in der Zweitsprache).

**Wie sich Bedürfnisse unterscheiden** (jedes hat eine Abhängigkeit, bei der meine künftige Arbeit ansetzt):

| Bedürfnis | Methode | Abhängigkeit |
|---|---|---|
| Sehen | Screenreader / Vergrößerung | Spricht nur, was die Seite bereitstellt — kein Alt-Text = **Stille**; braucht starken Kontrast |
| Motorik | Nur-Tastatur / Switch-Zugang | *Alles* muss ohne Maus erreichbar sein (Tab + Enter) |
| Hören | Untertitel / Transkripte | Untertitelte, geprüfte Medien |
| Kognitiv | Einfache Sprache | Einfache Wörter, klare Struktur, ein Gedanke nach dem anderen |

### Meine eigene Arbeit barrierefrei machen

Ich muss kein Entwickler sein — vier Gewohnheiten in Werkzeugen, die ich ohnehin nutze:

<Steps>
1. **Alt-Text** — ein Satz, der sagt, was ein Bild zeigt und warum („Balkendiagramm: Umsatz steigt Jan–Jun, starker Sprung im April"). Rein dekorative Bilder als dekorativ markieren, damit Screenreader sie überspringen.
2. **Echte Überschriften + einfache Sprache** — die tatsächlichen Überschriften-*Stile* verwenden (nicht nur großen fetten Text — Screenreader navigieren über echte Überschriften). Kurze Sätze, gebräuchliche Wörter, Begriffe bei der ersten Verwendung erklärt.
3. **Farbe: Kontrast, und nie Farbe allein** — starker Text-/Hintergrundkontrast; Farbe niemals der *einzige* Bedeutungsträger sein lassen (ein rein roter Fehler ist bei Rot-Grün-Schwäche unsichtbar — ein Symbol/eine Meldung ergänzen: „Fehler: TT.MM.JJJJ verwenden").
4. **Untertitel & Transkripte für Medien** — Auto-Untertitel sind ein Entwurf, am schwächsten bei Namen und Fachbegriffen, also prüfen und korrigieren: *Maschinenausgabe, menschliche Prüfung* (dieselbe Regel wie bei KI).
</Steps>

<Aside type="tip" title="Barrierefreiheit ist ein professioneller Standard, keine Zusatzpunkte">
Der **European Accessibility Act** macht eine breite Palette digitaler Produkte/Dienste (Banking, E-Commerce, Verkehr, E-Books) EU-weit einschließlich Deutschland gesetzlich verpflichtend barrierefrei — **anwendbar seit 2025**. Gesetze verweisen auf **WCAG** (Web Content Accessibility Guidelines), zusammengefasst als **POUR**: **P**erceivable/wahrnehmbar (Alt-Text, Untertitel, Kontrast), **O**perable/bedienbar (Tastaturzugang), **U**nderstandable/verständlich (klare Sprache/Struktur), **R**obust/robust (funktioniert mit Screenreadern). Meine vier Gewohnheiten decken bereits ihren Kern ab — ein professioneller Vorteil in *jeder* Rolle auf der IT-Landkarte, von meinem ersten Arbeitsstück an.
</Aside>

## Wiederholungs-Zusammenfassung

| Kernpunkt | Kurz gemerkt |
|---|---|
| Bedrohungsmodell | Angreifer treffen alle im großen Maßstab; meine E-Mail ist der Generalschlüssel |
| Starkes Passwort | Länge schlägt Komplexität — eine Passphrase; nie wiederverwenden |
| 2FA | Zweiter Nachweis (Handy) — stoppt einen Dieb selbst mit dem Passwort |
| Malware-Abwehr | Zügig aktualisieren + bewusst entscheiden, was ich öffne/anklicke/installiere |
| Phishing-Muster | Dringlichkeit → Link → Aufforderung; direkt prüfen, nie über den Link der Nachricht |
| Schloss | Verbindung ist privat, nicht dass die Seite ehrlich ist — die Domain lesen |
| Verschlüsselung | Bei der Übertragung (HTTPS/VPN) vs. im Ruhezustand (gespeicherte Daten) |
| Backups | 3-2-1: 3 Kopien, 2 Medien, 1 extern — übersteht jedes Unglück |
| Fußabdruck | Durchsuchbar + beständig; Löschen tilgt nicht |
| Quelle beurteilen | Wer / Wann / Warum; über die Schlagzeile hinaus lesen |
| Fehl- vs. Desinformation | Ehrlicher Irrtum vs. bewusste Täuschung — die Absicht beurteilen |
| Verifizieren | Laterales Lesen + zum Ursprung zurückverfolgen + unabhängige Quellen |
| Ehrliche Nutzung | Ideen anerkennen, mit Anführungszeichen zitieren; Umformulieren ≠ Eigentum |
| Verantwortung | Online ist keine getrennte moralische Welt; auf die Behauptung eingehen, nicht auf die Person |
| Datenschutz / DSGVO | Meine Daten sind meine; Rechte zu erfahren, korrigieren, löschen — echte Bußgelder |
| Urheberrecht | Kein breites „Fair Use" in der EU; Erlaubnis oder Lizenz + Quellenangabe |
| Wohlbefinden | Ergonomie + Struktur schlägt Willenskraft; Deep ≠ Shallow Work |
| KI in einem Satz | Sagt voraus, weiß nicht — selbstsicher falsch ist das Standardrisiko |
| Prompten | Zweck + Kontext + Vorgaben; es ist ein Gespräch |
| KI-Grenzlinie | Keine personenbezogenen/vertraulichen Daten in KI-Werkzeuge |
| Barrierefreiheit | Frei von Barrieren — die Barriere ist die Gestaltung; dauerhaft/vorübergehend/situativ |
| Meine 4 Gewohnheiten | Alt-Text · echte Überschriften + einfache Sprache · Kontrast (nie Farbe allein) · Untertitel |
| Das Gesetz | European Accessibility Act (seit 2025) + WCAGs POUR-Prinzipien |
