*Generative AI for Managers — TUHH Institute of Entrepreneurship · part of my Technology Management MBA · my own study notes, rewritten in my words for revision.*

---

This was an intensive **6-day, hands-on course** on Generative AI, built for business students with **no or low coding background** — exactly the position I was in. It goes from *how LLMs actually work* all the way to *building a GenAI business case*, with a lot of practice in between using **Google Colab** and the **Gemini API**.

I rewrote the whole thing in my own words as study notes: the concepts explained plainly, the jargon defined the first time it shows up, and the hands-on labs summarised with the **notebooks attached for download** so I (or anyone) can open them in Colab and actually run them.

<Aside type="note">
**How each day worked:** ~90 min theory input → ~90 min guided lab → ~90 min independent lab → ~90 min in-class assignment. My notes follow the same rhythm: the concepts first, then what the labs and assignment had us build (with the notebooks to download).
</Aside>

<Aside type="caution">
**On API keys:** the labs use a Gemini API key. Never hard-code a key into a notebook or paste it into shared files — store it in Colab **Secrets** and read it from there. The [Setup](/learnings/mba/generative-ai-for-managers/00-setup/) page shows the safe way.
</Aside>
