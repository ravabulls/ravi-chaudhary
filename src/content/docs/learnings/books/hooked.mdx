## Three things to remember

<CardGrid>
  <Card title="1 · The Hook is a loop" icon="open-book">
    Trigger, Action, Variable Reward, Investment — round and round. Each pass tightens the cue-to-behaviour bond and makes leaving costlier. Habits are built by repetition, not willpower.
  </Card>
  <Card title="2 · Uncertainty is the engine" icon="star">
    Predictable rewards satisfy, then bore. Rewards that vary in timing or size create craving. The next email *might* matter — that "might" is what keeps you checking.
  </Card>
  <Card title="3 · The user's own effort locks them in" icon="approve-check">
    Every bit of data, time, or reputation a user puts in raises their switching cost and pre-loads the next trigger. We value what we labour for.
  </Card>

## The big idea

Why do some products become habits while equally good ones get abandoned? Eyal's answer is a four-step cycle — the **Hook Model**: Trigger to Action to Variable Reward to Investment. Each turn deepens the association between a cue and a behaviour, lowers the effort to act, and increases what the user has stored inside — until leaving feels like loss. The same mechanism runs everything from an addictive app to a morning routine, and it comes with a built-in ethical test that separates a genuine helper from an exploiter.

## The key ideas

<CardGrid>
  <Card title="Triggers — external then internal" icon="information">
    An **external trigger** is explicit: a notification, a badge, a button. An **internal trigger** is a feeling — boredom, anxiety, loneliness — that becomes wired to a behaviour. The strongest hooks run on internal triggers, because then no prompt is needed at all.
  </Card>
  <Card title="Action — Fogg's B = MAP" icon="puzzle">
    A behaviour happens only when **Motivation**, **Ability**, and a **Prompt** arrive together: B = MAP. The common mistake is pouring effort into motivation when the real barrier is ability. Reduce friction first — make the action simpler.
  </Card>
  <Card title="Variable Reward — tribe, hunt, self" icon="star">
    Three flavours of unpredictable payoff: **Tribe** (social validation, belonging), **Hunt** (information, resources), and **Self** (mastery, completion). Variability is what turns a satisfying reward into a compelling one.
  </Card>
  <Card title="Investment — loads the next trigger" icon="magnifier">
    When users put in data, effort, or social capital, they raise their switching cost and pre-load the next cycle. Investment makes the hook self-reinforcing — the more you've put in, the more you'd lose by leaving.
  </Card>
  <Card title="The Manipulation Matrix" icon="approve-check-circle">
    Two questions — would the maker use it, and does it improve the user's life? — give four quadrants: **Facilitator** (yes/yes, the target), **Peddler**, **Entertainer**, and **Dealer** (no/no, the floor). A moral audit built into the design.
  </Card>
</CardGrid>

## How to use it

<Steps>

1. **Map any sticky product against the four steps.** Name the trigger, the action, the variable reward, and the investment. A missing or weak link explains poor adoption better than any survey.

2. **Reduce friction before adding motivation.** If a behaviour won't stick, make the core action simpler first — fewer steps, fewer fields, faster access. Motivation piled onto a hard action just produces resentment.

3. **Find or build the variable reward.** Locate the genuine unpredictability — the occasional real payoff — and make it visible instead of burying it in averages.

4. **Ask for a small investment early.** Have the first use store something the user would miss — a tag, a note, a setup — so the first trigger of the next cycle is already loaded.

5. **Run the Manipulation Matrix before shipping.** Would you use it, and does it genuinely help? If either answer is no, redesign. The facilitator position is both the ethical one and the durable one.

</Steps>

## Lines worth keeping

> *"The Hook Model is designed to connect the user's problem with the company's solution with enough frequency to form a habit."*

> *"Behaviour is driven by internal triggers more than external ones."*

> *"Variable rewards are one of the most powerful tools that companies use to hook users. Research shows that levels of dopamine surge when the brain is expecting a reward."*

> *"The more users invest time and effort into a product or service, the more they value it. In fact, there is ample evidence to suggest that our labour leads to love."*

> *"Habits are not formed by rewards alone. There must be a feedback loop, and that loop must be repeated many times before a behaviour becomes automatic."*
